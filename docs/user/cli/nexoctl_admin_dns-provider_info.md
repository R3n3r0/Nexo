# nexoctl admin dns-provider info

Show a DNS provider (never its credentials)

```
nexoctl admin dns-provider info ALIAS NAME [flags]
```

## Options

```
  -h, --help   help for info
```

      --no-color            disable colors (also with the NO_COLOR environment variable)
