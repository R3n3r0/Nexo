I codici raggruppati del catalogo (`D-ACC-01..04`, `D-CCH-01..08`, `D-DST-01..08`) sono espansi con le descrizioni di [10](../docs/10-domini-accessi-distribuzioni.md) e [11](../docs/11-cache-domini.md). Il test `internal/tools/traceability` fallisce se una funzionalità P0/P1 non ha test, se un tag nomina un codice fuori catalogo o se questo file non è aggiornato.
