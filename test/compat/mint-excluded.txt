# Expected failures of the MinIO Mint suites (run-mint.sh): the tests of
# the suites that exercise what Nexo does not provide or answers otherwise.
# One line per test (a glob of the function name the suite reports):
#
#   <suite> | <function> | <category> | <reason>
#
# The categories are those of excluded.txt (rgw, deprecated, p2,
# out-of-catalog, aws, design, suite) plus "minio": an API or behavior of
# MinIO that is not part of S3 (Admin API, MinIO extensions). A failure
# listed here is reported as expected; any other failure fails the run.
#
# The glob matches the test name (minio-go, minio-py: the part after
# "<suite>:") or "<function> <args>" (the suites that report the API call,
# such as minio-js).
