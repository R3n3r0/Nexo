# Tests of ceph/s3-tests (every functional file run by run-s3tests.sh:
# test_s3.py, test_headers.py, test_iam.py, test_sts.py, test_s3select.py,
# test_sns.py, test_s3control.py) that do not apply to Nexo, deselected by
# run-s3tests.sh. One exclusion per line:
#
#   <selector> | <category> | <reason>
#
# The selector is a test name ("*" and "?" are wildcards, brackets are
# literal: a parametrized test can be named with its parameters) or
# "marker:<name>"; the first matching line gives the category and reason
# reported for the test. The category says how the reason is verified:
#
#   rgw             the suite marks the test itself (fails_on_aws, an RGW
#                   extension marker): RGW behavior that AWS S3 does not have
#   deprecated      API deprecated by AWS, a non-goal of Nexo (Signature V2,
#                   BitTorrent): docs/01 §1.1
#   p2              feature P2 of the docs/02 catalog (ID in the reason),
#                   planned after v1.0 (docs/05 M10)
#   out-of-catalog  AWS API outside the docs/02 catalog (IAM, STS with IAM
#                   roles, SNS, S3 Control, server access logging, website
#                   and public access block S3 APIs)
#   aws             the test expects RGW's answer where Amazon S3 answers
#                   otherwise; Nexo answers as S3 (docs/02 §2.4)
#   design          documented difference of Nexo (docs/02 §2.4)
#   suite           the test cannot send the request it describes (botocore
#                   rewrites the header the test sets; the suite marks it
#                   fails_on_rgw with a TODO saying so)
#
# NEXO_S3TESTS_CHECK_EXCLUDED=names runs the tests excluded by name too
# and fails when one of them passes (its exclusion is no longer
# justified); the report lists the selectors that match no test.
