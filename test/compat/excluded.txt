# by run-s3tests.sh. One exclusion per line: "<selector> | <reason>", where
# the selector is a test name ("*" and "?" are wildcards, brackets are
# literal: a parametrized test can be named with its parameters) or
# "marker:<name>"; the first matching line gives the reason reported for
# the test. Every exclusion names the feature it depends on and why Nexo
# does not provide it (docs/02 catalog, docs/05 roadmap), or the Ceph RGW
# behavior the test expects where S3 (and Nexo) behave otherwise. The
# report lists the selectors that match no test.
