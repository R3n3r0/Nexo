# Security policy

## Supported versions

Security fixes are released for the latest minor version of Nexo. Upgrade to the most recent release before
reporting an issue.

## Reporting a vulnerability

Please do **not** open a public issue for security problems. Report them privately through
[GitHub private vulnerability reporting](https://github.com/R3n3r0/Nexo/security/advisories/new) or by e-mail to
<paolorusso1991@gmail.com>.

Include the Nexo version (`nexo --version`), the deployment mode, the steps to reproduce and the impact you
observed. You will receive an acknowledgement within a few days; once a fix is available, the advisory is published
together with the release that contains it.

The threat model and the results of past penetration tests are in [docs/security](docs/security).
